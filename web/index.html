How it works

Four questions. Then we handle it.

01

Set a budget

The most you'll ever pay. That's the only number you choose.

02

Every real view a creator gets you mints one coin. Fakes mint nothing.

03

Your budget backs all the coins. More views, cheaper coins.

04

What you can count on

Two promises. Kept every time.

Budget

Never a rupee over.

Not "usually". The price is budget ÷ coins, so it can't go over. It's maths, not a forecast.

Fraud

Bought views don't get paid.

Bought views arrive in a burst and stop dead. Real ones fade slowly. We hold the cliffs, check them, and never pay for fakes.
